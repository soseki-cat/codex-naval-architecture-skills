# 拟合与数据门禁

“真实拟合”不是把曲线画顺，也不是用插值补齐所有空白。它要求来源、错误判断、
拟合假设和验收证据均可复查。

## 必须先审计

以下任一项未完成时，不得进入正式绘图：

- 表类型、单位、站号方向、水线高度和坐标约定已确认。
- 空白、零值、文本、多分支值、可疑科学计数法和超尺度值分别记录。
- 检查同水线邻站突变，不能直接替换。
- 检查同站相邻水线的顺序是否反转，尤其注意艉部和艏部。
- 检查连续曲线段和断点，不能跨未知段连接。
- 已识别物理多值外形、球鼻艏、艉悬伸等可能本身就会造成投影交叉的情况。

运行：

```text
python <skill>/scripts/audit_offsets.py \
  --csv <offsets.csv> \
  --config <parameters.json> \
  --report <audit.json>
```

审计报告是拟合前的证据，不是修订授权。

## 询问用户

发现实质异常时，先暂停并列出：

- 可疑单元格或站段；
- 原值、单位和邻域对比；
- 异常类型：孤点、连续折返、水线顺序反转、单位疑点、多分支、缺失；
- 建议方法及预计会影响的数据范围；
- 哪些内容必须由用户确认，哪些可以保留为 `REVIEW`。

示例：

> 在 `0.5 站 / 12000WL`、`2.5 站 / 6000WL` 和 `18 站` 的相邻水线发现明显反序；另外艉部多站存在连续顺序反转。它们是原始错误、OCR 错误，还是真实外飘/悬伸？如果按“同舷水线不相交”处理，预计会改动约 250 个半宽值。请确认是否授权拟合，或提供更正值。

用户未授权时，只提交审计结论，不写修正表，不生成正式 DXF。

## 拟合分级

| 类型 | 用途 | 必要证据 |
| --- | --- | --- |
| 原始点连接插值 | 连接已知连续段 | 原始点、区间、PCHIP 节点误差 |
| 单格异常修订 | 替换有明确证据的孤点 | 目标清单、邻域、横剖交叉核验 |
| 全表保序拟合 | 消除水线顺序反转 | 用户授权、改动数量、单调约束、全对水线检查 |
| 曲面光顺 | 调整三维曲面 | 超出本技能默认范围，必须有曲面算法和验收标准 |

保形 PCHIP 只保证在指定数据点之间不产生插值振铃，不自动证明曲线是工程光顺的。
单调保序拟合也不能证明型线就是原船真实测量值。

## 验收

拟合后至少核对：

- 原始表和新表只有授权范围内的差异；
- 每个估算值有原值、最终值、方法和依据；
- 已知连续段内没有把缺失值补成零；
- 同站水线顺序无反转；
- 同舷水线按共同 x 范围做全对相交检查；
- 横剖和水线来自同一最终矩阵；
- DXF 回读、SPLINE 节点误差和语言版几何一致；
- 原生 CAD/Rhino 未打开时明确标 `NOT_CHECKED`。
