# 输出语言与双语交付

## 单语判断

按以下优先级设置 `languages`：

1. 用户明确说了输出语言。
2. 用户当前请求的主要语言。
3. 主输入表、图纸标题或随附说明的主要语言。

中文请求一般为 `["zh"]`，英文请求一般为 `["en"]`。单语输出不附带另一语言的
标题、说明、表格、注释和报告。语言无法判断且选择会影响结果时，先询问用户。

输入可以是截图、中文型值表或英文 CSV；来源语言与输出语言不一致时，保留来源
原文和术语映射，但成图文字使用用户要求的语言。

## 双语与开源发布

只有以下情况生成双语：

- 用户明确要求中英文；
- 仓库 README、技能发布页或其他开源发布材料需要面向两种语言；
- 合同、交付规范或既有项目明确要求双语。

双语交付必须是两个完整版本：

- `Chinese/` 与 `English/` 各自包含横剖、水线、纵剖；
- `hull_lines_Chinese.dxf` 与 `hull_lines_English.dxf` 各自包含完整三视图；
- 标题、注释、表格、错误报告和预览不混用语言；
- 文件可以共享同一源数据、几何签名和验证报告，但文本资源不能互相覆盖；
- 两种语言逐一比较曲线数、源点数、图层语义和几何签名。

“同一 DXF 内左右并排中英文”不算独立双语版本；除非用户明确要求对照版。

## 文件名

- 中文单语：优先 `zh/`、`hull_lines_zh.dxf` 或保留脚本兼容文件名。
- 英文单语：优先 `en/`、`hull_lines_en.dxf` 或保留脚本兼容文件名。
- 开源双语：`Chinese/`、`English/`、`hull_lines_Chinese.dxf`、
  `hull_lines_English.dxf`。

文件名和目录规则必须写进输出报告。不得因某一语言缺少字体而把另一语言的文字
复制到该版本。
