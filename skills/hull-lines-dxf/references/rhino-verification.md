# Rhino 骨架核对与图层整理

## 资料与物理坐标

实际有 `.3dm`、可用 Rhino 会话或可读几何文件才做软件/几何实测；摘要与截图只能作为其提供者的报告。无法访问原生软件时继续数据与文件检查，并明确证据边界。

2D 排版 DXF 的平移不是船体 3D 坐标。建骨架前还原视图排版，并确认真实纵向尺度；站号展示倍率不能当作站距。真实骨架采用 `X` 纵向、`Y` 半宽、`Z` 高度，核对单位、基线和原点。ST 固定 X，BP 固定 Y，WL 固定 Z；镜像与正负侧别显式记录。

`origin_station` 只对全部曲线和点作一致 X 平移，不能改型值。Y=0 为声明的 CL，Z=0 为声明的基线。原点与源曲线端点分别核对；非零 WL0 半宽无需被拖到原点或增添零点。仅有无 X 的 TRANSOM 时可验证单独横剖，不能猜其船体位置。

比较源型值、平面、站距比例、镜像和旋转；正确曲线仅需图层规范化时，不重拟合或修形。样例船型与历史检查数量不能当作本次验收常数。

## 有效域与交点

先约定绝对容差、单位与用途。按各曲线实际支持域判断 ST × BP/WL 是否应相交，不以补造曲线实现全部相交。

| 类别 | 证据 |
|---|---|
| 有效交点吻合 | 双方处于支持域，交点/最近点误差在约定容差内 |
| 现有范围外 | 半宽、高度或站域超出已有曲线范围，或未知底面没有对应交点 |
| 需检查 | 域内应相交却缺交点、误差超限、重复交点或分段对应不清 |

“范围外”不等于失败；不跨缺失段，不外推底面/甲板。原始型值中底部已有非零半宽时，内侧更低 BP 是否具有底部交点无法由外侧矩阵自动补出。源 BL 与推导 BP 分开报告，采样残差只是算法核对，不是制造或曲面光顺认证。

## 图层与交付

尊重现有命名，可分原始对象（保留、隐藏、锁定）、有效曲线、参考对象和默认关闭检查对象。修改前确认当前文档与输出位置；保存新文件，回读核对曲线数、平面、站距、图层与源对象。完整工作模型与干净骨架分别说明其内容。

报告实际访问文件、单位/坐标/原点、曲线及支持范围、三类交点结果、约定容差、保存与回读证据、未知数据、字体及软件显示状态。DXF 回读或库审查通过只证明对应文件检查；只有实际 Rhino/AutoCAD 实测才能报告其原生软件验证通过。
