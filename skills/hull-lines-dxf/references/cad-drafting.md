# CAD 制图、标注与交付

## 完整语言版本

`languages` 默认 `["zh", "en"]`，各语言完整独立交付；默认 `embedded_tables=true`、`annotations=true`。双语输出根目录为 `hull_lines_Chinese.dxf` 与 `hull_lines_English.dxf` 合并图，`Chinese/`、`English/` 内各有独立横剖、水线、纵剖图。仅选一种语言（如 `languages=["en"]`）时，在输出根目录保留旧名 `body_plan.dxf`、`waterline_plan.dxf`、`longitudinal_sections.dxf`、`three_views_combined.dxf`。用户明确指定的语言和视图覆盖默认。

同一数据生成两套几何，核对曲线、源点、颜色及表格内容一致；文字翻译不得改变数据。独立与合并图的排版平移必须可识别，不能混作船体坐标。新生成视图先分别标注再合并，以保持标签与引线的一致几何。

## 曲线、表格和标注

源点保留，连续已知段使用 PCHIP 并写为原生 SPLINE；一阶连续，不承诺二阶连续或工程光顺。逐曲线颜色帮助对应视图与标签，默认使用随线站号、WL/BP 端部引线。多段曲线分别标明，未知点或孤立点以说明标记表示。引线不是新增船体曲线。

参考网格可从标签下通过；曲线与文字的避让以船体曲线及已有文字为依据。新生成两版共同预留两种语言标题、说明和标签的尺寸；合并后标注元数据应指向平移后的实际源曲线，保留可核对的来源图层与实体句柄。

图内表格为格线加单元格居中 TEXT，包含已有水线半宽、甲板半宽、纵剖高度和修订记录；未知与原文状态不能消失。不承诺原生 `ACAD_TABLE`。只有用户请求时另交 Excel，不能以外部表替代已请求的图内数据表。

数据来源层、计算交点层、参考层和标注层分开；被替换的原始点保留在默认关闭的 `SOURCE_REPLACED_POINT` 或相应前缀层。仅半宽支持的甲板平面投影可选且默认关闭，不能显示成有高度依据的甲板纵剖。

## 仅更新已有 DXF 标注

```text
python <skill>/scripts/annotate_hull_lines.py --input <existing.dxf> --out <new.dxf> --config <parameters.json> --language zh
```

保存到新文件，禁止覆盖源文件。仅标注模式保留几何、数据、曲线颜色、表格和用户注释。使用工具自有标记识别并替换其上次生成标注，重复执行应幂等；不能按整层或所有 TEXT 盲删用户标注。回读并对比非工具标注实体及几何，记录标签数量、所有权标记和颜色保持证据。对于已有两种语言 DXF，旧文字的长度与占位可能不同，作为保留的障碍物可能导致两版新增标注位置不同；应报告差异，不修改旧文字来强行一致。

## 字体、预览与证据

按当前环境发现可用字体名称，允许配置覆盖；不固定 Windows 字体路径。依赖包含 `fonttools` 与 `Pillow`，用于字体发现、字形覆盖与文字尺寸度量。DXF 字体样式与预览字体需分别检查。预览缺少 CJK 字体时报告缺字及未验证状态，不能凭成功保存 DXF 宣称中文显示正确。字体报告中的 `glyph_coverage_checked` 只表示字形覆盖检查，`preview_rendered` 只表示已生成预览；两者不能自动等同于 `visual_review` 通过。原生 CAD 显示应保留 not tested，直到实际实测。人工或工具视觉检查另记录文字重叠、随线角度、引线与曲线混淆、表格截断和图幅比例。

纵向真实尺度未知时显示站号/显示单位，并在图内注明倍率不等于米制站距。独立横剖可按已确认米制设置；含站号纵向坐标的图不得错误声明全图为物理米制。仅物理尺度已知且请求时输出 `hull_skeleton_3d.dxf`。

## 输出检查

保留原始输入 CSV/JSON 副本、解析与绘图数据、授权修订台账、计算交点、验证报告和说明；文件名按当前脚本清单核对。报告至少含输出文件清单、各视图实际曲线/点、未生成原因、单位/纵向比例、修订结果、DXF 文件审查、字体与预览状态，以及原生软件验证证据。所有中文文本使用 UTF-8。

运行前选择新输出目录，避免覆盖已有已确认成果；依赖使用 `scripts/requirements.txt` 及同一个 Python 解释器。脚本不自动安装依赖；环境失败与文件几何失败分别报告。回读各 DXF 并检查结构、源点、SPLINE 误差、镜像、表格、颜色、标注和推导范围。文件存在不表示全部 BL/BP 成功，应核对逐项状态。

AutoCAD 操作说明：`OPEN` 打开 DXF，`Z` → `E` 显示全图，必要时 `SAVEAS` 为 DWG。没有实际进入 AutoCAD/Rhino 打开、检查或保存时，写明只完成文件回读、数值及预览检查；用户转述结果也应注明来源。
