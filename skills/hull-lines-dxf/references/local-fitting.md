# 局部授权拟合

疑似错误先保留原文和来源。先完成 [拟合与数据门禁](fitting-standards.md) 的审计，
再向用户报告疑点。只有用户明确授权后才能修订；不能以“更顺”修改其他型值。
接受 JSON 顶层列表或 `{"targets": [...]}`，每项必须含 `station` 与原表
`column`。

```json
{
  "targets": [
    {"station": 0.5, "column": "WL1", "method": "pchip_station"},
    {"station": 2, "column": "WL2", "method": "value", "value": 3150}
  ]
}
```

`method` 默认 `pchip_station`；`value` 方法必须有显式 `value`，数值单位与源半宽一致。`correction_decimals` 默认 0，按指定精度取整并保留未取整值。清单应能对应到用户授权，未知目标、重复冲突和不可解释值需在应用前拒绝。

整批目标先从拟合输入中排除，然后按真实站号比例对同水线已知站点做 PCHIP；不得让一处新估值成为同批另一处的依据。只在支持的局部域内估算，不跨未授权未知段，不外推。同站相邻水线的 PCHIP 是独立横剖方向检核，应排除批次目标；有支持域时记录方向差异，不能将检核值冒充主估值或实测。缺少双侧支持时报告检核 unavailable；这不等于主估算失败，不能声称每项都已完成检核。

修订为原子批次：所有目标计算完成并记录可用/不可用检核状态后统一提交；任一目标计算失败则原批次保持不变，并报告失败原因。显式 `value` 与拟合值同样标记为授权修订。保留原始、解析、估算及绘图值、方法、状态、未取整值、邻域与检核差异的台账；原始被替换点保留在默认关闭的独立图层。

横剖与水线从同一最终矩阵生成。源 BL 高度保持其来源属性，不能因半宽修订自动改写；受影响的推导交点需重新计算与验证。11122、11085、11072、11059 是已保存案例的回归示例值，绝不是通用目标、自动修正值或船型常数。

局部修订只证明所授权单元格的计算与保留策略，不代表完整曲面全局光顺、制造精度、闭合船体或原始测量被恢复。

若用户授权的是“全表保序/去交叉拟合”，而不是逐单元格清单，应在执行前先报告
预计改动数量和受影响站段；`refit_waterlines.py` 在未提供 `--approve-refit`
时会返回 `user_confirmation_required` 且不写正式输出。确认后生成的每个估算值
都要进入 `ESTIMATED` 台账。
