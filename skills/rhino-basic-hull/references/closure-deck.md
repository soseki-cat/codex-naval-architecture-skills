# 镜像、下部封闭、干舷与甲板

## 镜像与实际边界

对称船体先验收一侧，再关于用户中心面镜像；默认Y=0的XZ平面。读取实际结果检查镜像位置、原有对象是否仍存在、法向及每侧连接状态，不假定镜像必然已完成或方向正确。

ShowEdges检查所有实际裸边和非流形边，按位置、连通性、边数和资料域分类；先前“有四个缺口”的描述不能替代几何审计。DupEdge或原生边界复制保留原曲线；辅助对象独立图层。

原资料不能确定端封/底面时，先检查已有授权。允许最低限度近似则记录几何依据、平面/非平面假设、影响范围和ESTIMATED。未授权时指出具体缺失轮廓；不会凭主尺度补造“真实”封头。

## 下部补面

根据边界试Sweep2、规则边界EdgeSrf或合适方法。Sweep2第一版不重建截面、不大量加点；复杂度明显高于同边界简单表达时，选择简单且能检验的方案。Patch只作有理由的备用，不用它隐藏边界矛盾。

同位/部分重合的低区边界先检查，不添加重叠面或零面积带。必要的边拓扑分割和Join仅作用于副本；底层母面控制几何继续冻结。不要强迫端部收成资料不支持的尖点。

新增面先检查边界残差、Zebra、曲率和接缝，再连接副本。G0不足可调整新增面位置；应光顺且许可时再测试G1。MatchSrf只改变授权新面，检查其是否破坏另一条边或拉出数据域；不能为G2大改原船。

保留已接受的G0硬角并记录实际角度，不把它称G1。只完成下部时，剩余裸边应仅属于预期顶圈；验证顶圈连通/闭合且无底/端遗留边，无非流形。此时仍是开放壳体。

## 真实或估计 Deck Edge

授权上部阶段后，先读原Deck Edge、侧视轮廓、型深、舷弧与梁拱资料。D是主尺度约束，不单独确定全部甲板高度；UPPER DECK列在半宽表头下时读作半宽，不能直接当高度。

忠实恢复且缺资料、无近似授权：停止受影响上部，保留已完成下部与缺失清单。已允许合理估计：连续执行最低限度上部几何，明确估计轮廓及主尺度约束。沿用既有授权，不在每条线/每面后重复询问。

先做一侧低复杂度Deck Edge，检查Top/Side/Perspective、纵向单调性、半宽变化、舷弧与CurvatureGraph，再镜像。主尺度只约束总体，不能证明具体悬伸分配或端宽来自原船。

## 干舷与完整甲板

以现有上缘和Deck Edge为上下边界，根据艉/舯/艏变化选择Loft、Sweep2或EdgeSrf分区，不把整船简单垂直Extrude。先保证G0，应当光顺处比较G1；只调整新面或共同新母面控制行，冻结下部不变。

新分区接口、下部接口、端板转角分别验收：部分接口G1/G2不表示全船同等级。真舷边或端板硬角可继续G0，需明确接受依据。

甲板外边界左右对称、端部闭合、无重复/断点后，选Sweep2、Loft、EdgeSrf等低复杂度表达。梁拱按原资料；无资料但已授权估计时，轻微中心高两舷低，窄端按合理规则渐减，记录最大值及方法。不默认绝对平面，不复制示例0.15m。

完整连续甲板先作基础母版；货舱、烟囱等开口只有下一阶段获准才切。几何确认后Join，不用Cap掩盖复杂边界。保存源资料/独立工作面和最终连接副本，默认避免重合显示。
