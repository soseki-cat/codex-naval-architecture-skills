# 资料、坐标与 ST/BP 骨架

## 资料审查

读取实际附件和文件，不从失效链接、占位图片或示例数据生成“实测”几何。记录文件单位、模型单位、站位表、AP/FP对应、船长是LBP/LOA/LWL哪一种、半宽/全宽、基线/中纵面和有效资料域。用户声明发错的图不参与本项目校核。

明确的物理站位表优先。站号与AP/FP确认后，才用 `X=(s-s_origin)/(s_FP-s_AP)*LBP`；编号反向时保留分母符号。最大站号不能自行认定FP。单位推定用已知尺度作交叉证据，已转成米的数据不能再乘一次0.001。

源BP可能来自同一型值矩阵计算，其交点一致性说明坐标/表示一致，不是独立测量精度。空白/“-”是未知；数值0是已知值，含义由列/轴决定。

## 精确变换

确认二维图原点O、横向单位轴a、竖向单位轴b，且两轴正交。点p的图内坐标为 `u=(p-O)·a`、`v=(p-O)·b`，按源单位换算。参考原点不是船体型值点。

| 图 | 目标坐标，二维源恰在图平面内时 |
| -- | -- |
| Body plan/ST | `(X_station, ±u, v)`，正负由图中左右半剖面和目标舷侧决定 |
| Profile/BP | `(X_reference+u, Y_BP, v)` |
| Waterplane参考 | `(X_reference+u, ±v, Z_WL)` |

每条曲线从原坐标直接变换到绝对目标位置，不逐站相对Move。Orient3Pt用三点表达相同轴映射时，关闭不需要的缩放；必要的单位换算单独记录。原生脚本可使用变换矩阵，不应把未执行过的手工命令写成执行证据。

例如一个ST的图内下端距中心线5.930763、高度0，在X=0站应成为 `(0,5.930763,0)`，不是只平移后的 `(5.930763,0,0)`，也不是 `(0,0,0)`。图中左侧半剖面镜像一次；已有右舷曲线不重复镜像。

不使用SetPt/ProjectToCPlane去隐藏错误轴或意外非平面源数据。`hull_math.py`保留容差内法向分量、拒绝超出声明图平面的点；曲线对象应由真实原生刚性/单位变换完成，不通过采样点重新拟合。

## 骨架验收

先核对基准站和相邻站，再推广全站。ST固定X，BP固定Y；基线和中纵面参考正确不意味着每条曲线必须触及它们。只建用户指定舷侧。源曲线结构、长度按变换尺度、控制点对应、节点和权重均应可回查。

BP一个平面可有多段。保留段数、区间和源曲线方向，不补跨域连接。ST通常低Z→高Z，BP通常艉→艏；按用户或源资料另有约定时记录实际方向。

对双方有资料的ST/BP组合：各自与对应固定平面求交，比较同一物理位置，再直接Intersect核查。双方无有效截点记录 `OUTSIDE_SOURCE_DOMAIN`；只有一方有截点或截点错位，检查平面位置、单位、镜像、对象选择和拟合来源，不能直接移动控制点匹配。

保护源图层，新增ST/BP及Check图层。辅助datum点明确标为坐标参考；端点辅助对象保留实际几何位置。交互中的端点检查可用捕捉、参数或脚本，不假定环境一定有名为CurveEnd的独立命令。

验收后导出纯骨架和带源资料版本，回读单位、对象/分段数、固定平面与来源。用户只要求检查时不创建辅助几何；需要辅助对象的建模任务可在独立Check层创建。
